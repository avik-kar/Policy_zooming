# Policy Zooming
This repository contains the code of PZRLMF and PZRLMB, two adaptive discretization-based reinforcement learning algorithm for average reward MDPs.

Here is a list of python libraries that are needed to run the code.
1. Python                             3.9.7
2. scipy                              1.7.1
3. seaborn                            0.11.2
4. matplotlib                         3.4.3
5. numpy                              1.22.4

Link to the paper: https://arxiv.org/pdf/2405.18793
